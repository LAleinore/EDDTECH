# EduMind AI

> Полноценная образовательная AI-экосистема для iOS (Daryn Ustaz, MindCare, Inclusive AI).

## Возможности

1. **Daryn Ustaz (AI-помощник преподавателя)**:
   - Структурированный генератор поурочных планов.
   - Генератор интерактивных тестов (один ответ, несколько ответов, открытые вопросы) с режимом прохождения и проверки.
   - Объяснение сложных тем и генератор конспектов.
   - История материалов преподавателя.

2. **MindCare (Психологическая поддержка студентов)**:
   - Безопасный AI-диалог с детерминированным слоем безопасности (Safety Guardrails).
   - Дневник настроения с выбором эмоций и интерактивными графиками за неделю и месяц.
   - Дыхательные практики и техники расслабления с таймером.
   - Экстренная помощь и контакты доверия.

3. **Inclusive AI (Инклюзивное адаптивное образование)**:
   - Text-to-Speech (TTS) с регулировкой скорости и паузы.
   - Speech-to-Text (STT) для голосовых заметок.
   - AI Simplifier (упрощение сложных научных текстов, выделение ключевых понятий и пошаговые алгоритмы).
   - Общесистемные настройки доступности (Dynamic Type, высокий контраст, уменьшение анимаций).

4. **Платформа и Архитектура**:
   - Единая ролевая модель (Teacher, Student, Learner, Admin).
   - 3 языка интерфейса (Русский, Казахский, Английский).
   - Серверный AI Gateway с поддержкой Google Gemini, OpenAI и детерминированного Demo Fallback.
   - PostgreSQL схема с Row Level Security.
   - Премиальный дизайн-код iOS (Material 3 + Cupertino, цвета #7652D6 / #F7F7FB).
